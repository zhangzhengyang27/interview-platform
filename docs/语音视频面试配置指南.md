## 一、能力概览

| 面试模式 | 技术方案 | 状态 |
|---------|---------|------|
| 文本面试 | DeepSeek 纯文本（原有能力） | ✅ 可用 |
| 语音面试 | 豆包流式语音识别（ASR）+ 豆包语音合成（TTS） | ✅ 可用 |
| 视频面试 | RTC 音视频通道 + 豆包端到端实时语音大模型（SeedRealtime） | 需 RTC 应用凭证 |

三者共用**火山引擎**一家服务商，但使用**三套独立的凭证体系**（详见下文），不要混用。

## 二、环境变量配置

所有密钥仅存于服务端 `.env.local`，**不下发前端**。`.env.example` 已包含全部占位符。

### 完整变量清单

| 变量名 | 用途 | 获取位置 |
|--------|------|---------|
| `VOLC_API_KEY` | 语音 ASR/TTS 的 API Key（新版鉴权） | 语音控制台 → API Key |
| `VOLC_TTS_RESOURCE_ID` | TTS 资源模型（固定 `seed-tts-2.0`） | 无需改动 |
| `VOLC_ASR_RESOURCE_ID` | ASR 资源模型 | 默认 `volc.bigasr.sauc.duration` |
| `VOLC_TTS_VOICE_TYPE` | TTS 音色 | 默认自然女声 |
| `VOLC_S2S_APP_ID` | 端到端语音大模型 AppId（旧版鉴权） | 语音控制台 → 应用管理 |
| `VOLC_S2S_ACCESS_TOKEN` | 端到端语音大模型 AccessToken | 语音控制台 → 鉴权管理 |
| `VOLC_RTC_APP_ID` | RTC 应用 AppId | RTC 控制台 → 应用管理 |
| `VOLC_RTC_APP_KEY` | RTC 应用 AppKey | RTC 控制台 → 应用管理（需 MFA 验证） |
| `VOLC_ACCESS_KEY` | 火山引擎账号 AK | IAM → 密钥管理 |
| `VOLC_SECRET_KEY` | 火山引擎账号 SK | IAM → 密钥管理 |

> ⚠️ **关键认知**：火山引擎语音能力存在「新旧两套鉴权」：
> - **ASR/TTS（语音面试）** 用新版 **API Key**（`X-Api-Key` 请求头）
> - **端到端实时语音大模型（视频面试）** 用旧版 **AppId + AccessToken**
> - **RTC 音视频通道** 用 **RTC AppId + AppKey**（另一套）
> - **RTC OpenAPI 调用** 用 **账号级 AK/SK**（V4 签名）

## 三、语音面试配置（ASR + TTS）

### 步骤 1：开通豆包语音服务

1. 访问火山引擎语音控制台：https://console.volcengine.com/speech/new/setting/activate
2. 开通「语音合成 2.0」「流式语音识别」等服务（新用户有免费额度）

### 步骤 2：获取 API Key

1. 访问 https://console.volcengine.com/speech/app
2. 左侧菜单点「API Key」
3. 点「+ 创建 API Key」，复制完整的 Key（只展示一次）

### 步骤 3：填入 `.env.local`

```bash
VOLC_API_KEY="你的 API Key"
VOLC_TTS_RESOURCE_ID="seed-tts-2.0"
VOLC_ASR_RESOURCE_ID="volc.bigasr.sauc.duration"
VOLC_TTS_VOICE_TYPE="zh_female_shuangkuaisisi_uranus_bigtts"
```

> 若你开通的是「流式语音识别模型 2.0」，将 `VOLC_ASR_RESOURCE_ID` 改为 `volc.seedasr.sauc.duration`。

### 涉及的代码

| 文件 | 说明 |
|------|------|
| `src/lib/volcengine.ts` | 凭证读取、`isVoiceConfigured` 探测 |
| `src/lib/volcengine-voice.ts` | ASR/TTS 调用封装（鉴权头、请求体） |
| `src/app/api/voice/tts/route.ts` | TTS 合成代理接口（返回 base64 音频） |
| `src/app/api/voice/asr/route.ts` | ASR 识别代理接口（直连豆包 WebSocket） |
| `src/hooks/useSpeechRecognition.ts` | 前端录音 Hook（AudioContext 采集 PCM → WAV） |
| `src/components/VoiceInput.tsx` | 语音输入按钮（点击说话/停止） |
| `src/components/SpeakButton.tsx` | AI 朗读按钮（豆包 TTS 替换浏览器朗读） |

## 四、视频面试配置（SeedRealtime）

视频面试 = **RTC 音视频通道 + 豆包端到端实时语音大模型**，需要三套凭证。

### 步骤 1：获取端到端语音大模型凭证（AppId + AccessToken）

1. 访问 https://console.volcengine.com/speech/app
2. 记下应用的 **AppId**
3. 访问 https://console.volcengine.com/speech/auth 生成 **AccessToken**

```bash
VOLC_S2S_APP_ID="你的 AppId"
VOLC_S2S_ACCESS_TOKEN="你的 AccessToken"
```

### 步骤 2：开通 RTC 服务并创建应用

1. 访问 https://console.volcengine.com/rtc
2. 首次进入需「领取礼包并开通」实时音视频服务
3. 进入「应用管理」，记录默认应用的 **AppId**
4. 点「应用配置」，查看主 **AppKey**（需手机 MFA 二次验证）

```bash
VOLC_RTC_APP_ID="你的 RTC AppId"
VOLC_RTC_APP_KEY="你的 RTC AppKey"
```

> ⚠️ **AppKey 查看需要手机短信二次认证**（10 分钟有效），这是火山引擎的安全机制。

### 步骤 3：获取账号级 AK/SK

1. 访问 https://console.volcengine.com/iam/keymanage/
2. 为子账号创建 AccessKey（建议用子账号，避免主账号密钥）
3. 记录 **AccessKey ID** 和 **SecretKey**（Secret 只展示一次）

```bash
VOLC_ACCESS_KEY="你的 AccessKey"
VOLC_SECRET_KEY="你的 SecretKey"
```

### 涉及的代码

| 文件 | 说明 |
|------|------|
| `src/lib/video-interview.ts` | `startVoiceChat`/`stopVoiceChat`（RTC OpenAPI）、`generateRtcToken` |
| `src/app/api/video-interview/token/route.ts` | RTC Token 签发（HEAD 探测配置状态） |
| `src/app/api/video-interview/start/route.ts` | StartVoiceChat 让 AI 面试官入房 |
| `src/app/api/video-interview/save/route.ts` | 转写结果落库 |
| `src/components/VideoInterviewView.tsx` | 视频通话界面（RTC 建连 + 实时字幕） |

> 视频模式未配置完整凭证时，前端会自动隐藏/禁用入口（`isSeedRealtimeConfigured` 探测）。

## 五、本地 HTTPS 配置（麦克风/摄像头必需）

`navigator.mediaDevices`（麦克风/摄像头 API）**只在安全上下文（HTTPS 或 localhost）下可用**。局域网 `http://192.168.x.x:3001` 会被浏览器禁用麦克风，必须配置 HTTPS。

### 步骤 1：安装 mkcert

```bash
brew install mkcert
mkcert -install  # 需要 sudo，输入 Mac 登录密码
```

### 步骤 2：生成证书

```bash
cd interview-platform
mkcert -key-file certs/localhost-key.pem -cert-file certs/localhost.pem \
  localhost 127.0.0.1 192.168.1.4
```

> 将 `192.168.1.4` 替换为你的实际局域网 IP（`ipconfig getifaddr en0` 查看）。

### 步骤 3：启动 HTTPS 服务

```bash
npm run dev:https
```

服务启动后访问 `https://localhost:3001`（本机）或 `https://192.168.1.4:3001`（局域网设备）。

### 手机访问需额外安装 CA 证书

1. 将 CA 根证书传到手机：`~/Library/Application Support/mkcert/rootCA.pem`
2. iOS：设置 → 通用 → VPN与设备管理 → 安装描述文件
3. Android：设置 → 安全 → 加密与凭据 → 安装证书

### 涉及的文件

| 文件 | 说明 |
|------|------|
| `server.js` | HTTPS 自定义开发服务器 |
| `certs/` | 本地证书（已被 `.gitignore` 忽略，不提交） |
| `next.config.ts` | `allowedDevOrigins` 允许局域网访问 |

## 六、验证与排障

### 验证语音面试

```bash
# TTS（应返回 base64 音频）
curl -X POST http://localhost:3001/api/voice/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"你好，欢迎参加模拟面试"}'

# ASR（用一段 WAV 音频）
curl -X POST http://localhost:3001/api/voice/asr \
  -H "Content-Type: application/json" \
  -d '{"audio":"<base64 wav>"}'
```

### 验证视频面试配置

```bash
# HEAD 返回 200 表示配置齐全，503 表示缺少凭证
curl -I http://localhost:3001/api/video-interview/token
```

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| `load grant: requested grant not found` | 用了旧版 AppId+Token 鉴权调用新版 ASR/TTS | 改用 `VOLC_API_KEY`（API Key 鉴权） |
| `requested resource not granted` | ASR 资源 ID 与开通的版本不符 | 检查 `VOLC_ASR_RESOURCE_ID`（1.0 用 `volc.bigasr.*`，2.0 用 `volc.seedasr.*`） |
| 麦克风按钮禁用 | 非安全上下文（HTTP 局域网） | 配置 HTTPS（见第五节） |
| 视频通话 SDK 加载失败 | CDN 地址错误（历史问题） | 已改用 npm 包 `@volcengine/rtc` |
| `Requested device not found` | 浏览器无摄像头/麦克风设备 | 检查设备连接与浏览器权限 |

## 七、成本说明

| 能力 | 计费方式 | 参考价格（2026-08） |
|------|---------|-------------------|
| 豆包 TTS | 按字符计费 | 约 2.8 元/万字符 |
| 豆包 ASR | 按时长计费 | 约 0.02~0.075 元/分钟 |
| SeedRealtime 视频 | 按分钟（音视频） | 约 0.035 元/分钟（720P） |

- 新用户有免费额度（如语音合成 2 万字符、流式识别 100 万 token、SeedRealtime 约 180 分钟）
- 面试场景用量极小，按量付费几乎可忽略
- 语音/视频实时流直连火山引擎，不经服务端中转，无带宽成本
