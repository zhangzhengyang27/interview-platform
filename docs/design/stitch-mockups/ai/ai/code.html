我想复习一下 React 的 Hooks，特别是 useEffect 的依赖项数组的工作原理。

smart_toy
SYSTEM COMPILER

很好的问题。useEffect 的依赖项数组（dependency array）用于控制副作用的执行时机。React 使用 Object.is() 算法来比较数组中每个依赖项的当前值和上一次渲染时的值。

核心规则：

  • 没有数组：每次渲染后都会执行。
  • 空数组 []：仅在组件挂载和卸载时执行。
  • 有依赖的数组 [a, b]：当 a 或 b 发生变化时执行。
javascript 
useEffect(() => {
  const subscription = props.source.subscribe();
  
  // 清理函数
  return () => {
    subscription.unsubscribe();
  };
}, [props.source]); // 仅当 props.source 改变时重新订阅
